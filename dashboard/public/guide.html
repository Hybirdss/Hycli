Start with what you want to do. Hycli handles the connection, actions and local results.

Prepare your first website

  1. Open AI connections and connect a provider. API-key connections use your provider key. ChatGPT login uses an installed Codex CLI.
  2. Open Websites, enter the address and choose an AI. Add a short task under What would you like to do? when you have a particular outcome in mind.
  3. Follow progress. Hycli checks the available documentation and browser capabilities, prepares actions and verifies safe reads. Open Explore actions to see the inputs and results.

Use the account you already have

Preparation can find and verify a saved browser session. You can also connect from Accounts. If several identities are available, choose the account you want. A separate API key belongs in Explore actions → Website API keys.

Connect your coding agent once

Open Coding agents → View connection settings and copy the configuration for this device. The general MCP connection prepares missing websites and executes newly installed actions:

hycli mcp

The packaged skills/hycli/ and agent/AGENTS.md provide reusable guidance. The matching CLAUDE.md has the same content.

Work from the terminal

hycli prepare https://your-website.example --intent "Find saved references"
hycli describe
hycli describe SITE ACTION
hycli SITE ACTION --help
hycli run SITE ACTION --arg query="design systems"

Replace the sample URL and IDs with your website and the names returned by describe. The actual action tells you which inputs it accepts. Use hycli jobs show JOB_ID --watch to follow work.

Review a change once.

Read actions can run directly. Changes return a receipt for review in this dashboard. Follow the existing receipt instead of sending a duplicate request. If an interrupted change has an uncertain result, check the website before trying again.

When an action needs help

A sign-in request belongs in Accounts; a provider issue belongs in AI connections. If the website changed, prepare it again with a clear task. Hycli can use documented JSON, forms, GraphQL and structured HTML, including rendered GET pages. Arbitrary browser clicks, multipart uploads and binary downloads are outside the current operation contract.

Settings shows the active data directory and credential protection. Website definitions, accounts and activity stay there, separate from the executable and public source package.
