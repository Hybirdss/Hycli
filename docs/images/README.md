# README visuals

`dashboard.png` is a capture of the unmodified Hycli dashboard, running with an isolated example workspace. Website cards, actions and account labels are illustrative data; they are not a list of verified integrations. No live account or credential is included.

`preparation.gif` records the real preparation UI against the isolated local website and AI-provider fixtures from `examples/dashboard_fixture.rs`. The animated bird, worker states and work notes are rendered by the application.

The other screenshots also use isolated demonstration data. The bird animation's source material is documented in [the motion provenance](../design/motion/PROVENANCE.md).
