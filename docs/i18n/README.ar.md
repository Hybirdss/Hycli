<a id="get-started"></a>
أدخل النطاق، ويمكنك كتابة الهدف في الحقل المجاور. يفهم الذكاء الاصطناعي الموقع أولًا ويختار مسارات عمل مفيدة، ثم يتحقق من المتطلبات والمدخلات والنتائج النهائية. إذا كانت هناك خطوات ناقصة، يبقى الموقع بحاجة إلى مراجعة.

## البدء

**[تنزيل v0.1.0 · Linux x64](https://github.com/Hybirdss/Hycli/releases/tag/v0.1.0)** · glibc ≥ 2.39 · [SHA-256](https://github.com/Hybirdss/Hycli/releases/download/v0.1.0/hycli-0.1.0-linux-x64.tar.gz.sha256)

Hycli تطبيق بلغة Rust مزوّد بلوحة تحكم محلية في المتصفح. من هذه النسخة من المستودع، ابنِ لوحة التحكم والملف التنفيذي:

```sh
node scripts/build.mjs
./dist/hycli dashboard
```

تفتح لوحة التحكم على `http://127.0.0.1:4318`. استخدم `hycli dashboard --no-open` لعرض العنوان دون فتح المتصفح، أو `--port 4320` لاختيار منفذ آخر. محرك المواقع ولوحة التحكم مضمّنان في الملف التنفيذي نفسه.

1. افتح **اتصالات الذكاء الاصطناعي** واربط مزوّدًا.
2. أضف عنوان موقع واختر خدمة الذكاء الاصطناعي التي ستجهّزه.
3. راجع العمليات المتاحة. نفّذ إحداها في لوحة التحكم أو افتح **وكلاء البرمجة** لنسخ إعدادات MCP مرة واحدة.

للمواقع التي تتطلب تسجيل الدخول، اربط الحساب من **الحسابات**. يمكن حفظ عدة حسابات للموقع الواحد؛ وتختار أنت الحساب الذي تستخدمه أدواته.

<a id="what-your-ai-can-do"></a>
## ما يمكن لمساعدك الذكي فعله

يحوّل Hycli العمليات المدعومة في المواقع إلى أدوات ذات أسماء وأنواع بيانات محددة. تشرح الأوصاف التي يكتبها الذكاء الاصطناعي ما تنجزه كل عملية، وما تحتاجه من معلومات، وما تعيده من نتائج.

يتولى ثلاثة وكلاء مستقلين للذكاء الاصطناعي القراءة والبحث، وسير العمل المفيد، وأدلة الحساب. تعرض لوحة التحكم المراحل المكتملة وحالة كل وكيل والوقت المنقضي وملاحظات العمل بلغة واضحة. ويظهر عمل واجهة سطر الأوامر وMCP في سجل النشاط نفسه.

<p align="center">
  <img src="../../docs/images/preparation.gif" alt="ثلاثة عمّال. وطائر صغير مشغول جدًا." width="100%" />
</p>
<p align="center"><sub>ثلاثة عمّال. وطائر صغير مشغول جدًا.</sub></p>

يعتمد التجهيز على معلومات متاحة فعلًا من الموقع: الوثائق المرتبطة، ومخططات API، وكود JavaScript المنشور، وبُنى الطلبات التي ترصدها إضافة المتصفح. بعد سير العمل المخطط له، يواصل العمّال المرور عبر كل عملية API موثّقة ليس لها إجراء بعد، حتى تُنفَّذ كل واحدة أو يُذكر سبب تعذّرها؛ ويعرض `coverage` في المهمة ما تبقّى. يمكنه إجراء عمليات قراءة محدودة للتحقق من عملية. ولا ينشئ سجلات اختبار، أو يعدّل محتوى، أو يحذف عناصر، أو يخمّن قوائم كبيرة من نقاط الاتصال، أو يرسل مدخلات اختبار عشوائية إلى خادم فعلي.

| العملية | السلوك |
| --- | --- |
| القراءة أو البحث | تُنفّذ تلقائيًا عندما تستند العملية إلى أدلة وتصنّف كعملية قراءة. |
| الإنشاء أو الإرسال أو التعديل أو الحذف | متوقفة حتى تسمح بالتغييرات لذلك الموقع. بعدها تُعرض بيانات الموقع والحساب والعملية والمدخلات النهائية لتوافق عليها. |
| أثر غير واضح | تلزم المراجعة قبل إرسال الطلب. |
| المصادقة أو التحقق الإضافي أو حد الطلبات | تُوقف الطلبات المتأثرة مؤقتًا، ويمكنك إعادة الاتصال أو الانتظار. |

يبدأ كل موقع للقراءة فقط. تبقى إجراءات التغيير فيه مخفية عن MCP ومرفوضة من واجهة سطر الأوامر إلى أن تفعّل **السماح بالتغييرات** في تفاصيل ذلك الموقع؛ وإيقافها مجددًا يلغي الموافقات المعلّقة. المفتاح وزر الموافقة موجودان في لوحة التحكم فقط، ولا تمنح لوحة التحكم جلستها إلا للعنوان الذي يفتحه `hycli dashboard`، لذا لا يستطيع وكيل يستدعي Hycli تفعيل التغييرات أو الموافقة على طلبه بنفسه. والوكيل القادر على تشغيل أي أمر بصفتك يستطيع أيضًا قراءة ملفاتك؛ أبقِ هذه الوكلاء خاضعين لمطالبات الأذونات الخاصة بهم.

تسري الموافقة على طلب واحد محدد، وتنتهي بعد خمس دقائق، ولا يمكن استخدامها إلا مرة واحدة. يؤدي تغيير المدخلات أو الحساب أو بيانات تسجيل الدخول المحفوظة أو تعريف الأداة المثبّتة إلى إبطالها. تسري هذه الحدود نفسها عند التنفيذ من واجهة سطر الأوامر أو MCP أو لوحة التحكم. ولا تُعاد تلقائيًا محاولة تنفيذ الطلبات التي تغيّر البيانات.

يعتمد الدعم على الموقع. قد تحتاج الصفحة التي لا تتوفر لها وثائق قابلة للاستخدام أو عمليات مرصودة إلى متصفح مسجّل الدخول، أو SiteSpec يقدّمه المستخدم، أو مزيد من التجهيز. يوضح Hycli ما يستطيع دعمه دون الادعاء بأن لكل موقع API جاهزة.

### الإمكانات المدعومة

يدعم OpenAPI بصيغتي JSON وYAML وREST وGraphQL، وطلبات JSON والنماذج المرمّزة بصيغة URL. يمكن استخراج السجلات والروابط والصفحة التالية من HTML باستخدام محددات تمت ملاحظتها، وقراءة صفحات GET التي يعرضها Chromium محلي. إذا فشلت قراءة أثناء التجهيز، يراجع الذكاء الاصطناعي الأدلة ويصحح التعريف ويتحقق منه مجددًا.

لا تُدعم حاليًا تسلسلات النقر العشوائية أو رفع multipart أو التنزيلات الثنائية. لا تتضمن الحزم حسابات أو أدوات CLI مولّدة مسبقًا.

## اتصالات الذكاء الاصطناعي

| الاتصال | تسجيل الدخول |
| --- | --- |
| ChatGPT · API key | مفتاح OpenAI API الخاص بك |
| Claude | مفتاح Anthropic API الخاص بك |

| Z.ai | مفتاح Z.ai API الخاص بك |

اختر نموذجًا في لوحة التحكم، بما في ذلك النماذج المتاحة لحسابك تحديدًا. تتحقق اختبارات الاتصال من المزوّد والنموذج المحدد. يحمّل مزوّدو API رسوم الاستخدام على حسابك لديهم.

يستخدم اتصال Codex بروتوكول app-server الرسمي. لا يقرأ Hycli رموز OAuth الخاصة بـ Codex ولا ينسخها. يعمل النموذج في محادثة مؤقتة مع تعطيل تنفيذ العمليات عبر الملفات وسطر الأوامر والمتصفح والتطبيقات وMCP. وتتولى أدوات القراءة التي يتحكم بها Hycli تجهيز المواقع.

<a id="use-hycli-with-your-ai"></a>
## استخدم Hycli مع مساعدك الذكي

**وكلاء البرمجة → عرض إعدادات الاتصال**

يشمل اتصال MCP العام تجهيز المواقع وتنفيذ الإجراءات. صِل وكيلك مرة واحدة ليتمكن من تجهيز الأدوات الناقصة ومتابعة التقدم واستخدام الإجراءات الجديدة.

```sh
hycli mcp
```

استخدم `--sites-only` لإتاحة الإجراءات المثبتة فقط. يقتصر الاتصال التالي على موقع واحد.

```sh
hycli mcp --sites-only --only-site SITE
```

```json
{
  "mcpServers": {
    "hycli": {
      "command": "hycli",
      "args": [
        "mcp"
      ]
    }
  }
}
```

إذا لم يكن `hycli` ضمن PATH الخاص بالوكيل، فاستخدم مسار الملف التنفيذي الذي تعرضه لوحة التحكم.

يتوفر المسار نفسه عبر CLI. استبدل عنوان المثال و`SITE` و`ACTION` بموقعك والأسماء التي يعيدها `describe`.

```sh
hycli prepare https://your-website.example --intent "العثور على المراجع المحفوظة"
hycli request SITE "Add draft editing and publishing with full post content"
hycli describe
hycli describe SITE ACTION
hycli SITE ACTION --help
hycli run SITE ACTION --arg query="design systems"
hycli jobs show JOB_ID --watch
```

قبل إعادة محاولة إجراء فشل، افحص الموقع دون ذكاء اصطناعي:

```sh
hycli check          # كل موقع مثبّت
hycli check SITE
```

يسجّل التجهيز عمليات القراءة التي نجحت بالترتيب، بما فيها عمليات تمرّر معرّف نتيجة سابقة إلى التالية. يعيد `hycli check` تشغيلها، بعد أن يتأكد أولًا من هوية الحساب المحفوظ. يفرّق الحكم بين `signed_out` (أعد ربط الحساب) و`site_changed` (الحساب يعمل لكن الاستجابات لم تعد مطابقة؛ اطلب إصلاحًا)، إضافة إلى `blocked` و`unreachable`. لا ينفّذ أي تغيير أبدًا، وتتبع حالة الخروج الحكم. وتحصل عملاء MCP على الفحص نفسه عبر `hycli_check`.

عبر MCP، مرّر العنوان و`intent` إلى `hycli_prepare`، ثم تابع المهمة باستخدام `hycli_job` أو `hycli_result`. يستطيع `hycli_run` تنفيذ الإجراءات الجديدة قبل أن يحدّث العميل قائمة الأدوات. ابحث أولًا عن المعرّفات الداخلية باستخدام إجراءات القوائم أو البحث ذات الصلة. تبقى الأدوات `hycli_result` و`hycli_check` و`hycli_activity` متاحة في الوضعين، ليتابع الذكاء الاصطناعي ملاحظات العمل والتقدم والنتائج المعتمدة، ويميّز بين تسجيل دخول منتهي وموقع تغيّر.

تعيد إجراءات التغيير إيصالًا لمراجعته في لوحة التحكم. تابع نتيجته دون تكرار الطلب. يؤدي فشل القراءة أو ورود استجابة غير متوقعة إلى حالة فشل في CLI أيضًا.

## تسجيل الدخول عبر المتصفح

يبدأ تجهيز الموقع بفحص نظام التشغيل الحالي والمتصفحات العاملة والمسجّلة وملفات التعريف المتاحة. يختار الذكاء الاصطناعي من هذه الإمكانات قراءة الوثائق وعرض الصفحات واستيراد جلسة الموقع والتحقق من الاتصال. تبقى مسارات المتصفح وملفات التعريف على الجهاز المحلي؛ ولا يعتمد تعريف الموقع المُنشأ على مسارات تثبيت المطوّر.

يمكن استيراد ملفات تعريف الارتباط وبيانات التخزين الخاصة بالمصدر من Chrome وChromium وEdge وBrave وFirefox عندما تكون متاحة. تدخل جلسة الموقع المطلوب وحدها إلى مخزن Hycli المحلي. يختار Hycli هوية واحدة مؤكدة تلقائيًا؛ وتُحسب ملفات التعريف التابعة للهوية نفسها خيار حساب واحدًا. ويحتفظ بالحساب المحدد سابقًا؛ أما الهويات المؤكدة المختلفة فتتطلب الاختيار بينها.

في **الحسابات ← ربط حساب**، يعيد خيار **اعثر على تسجيل دخولي** هذا البحث. إذا لم يجد جلسة صالحة للاستخدام، يفتح خيار **فتح صفحة تسجيل الدخول إلى الموقع** الموقع في متصفحك الافتراضي. يعيد Hycli التحقق ما دام مربع الحوار مفتوحًا، ولا يستأنف التجهيز إلا بعد التحقق من الحساب المحدد. لا يُعدّ فتح علامة تبويب وحده دليلًا على نجاح تسجيل الدخول.

قد تحتاج الجلسات المحمية بنظام التشغيل أو المرتبطة بالمتصفح أو الخاصة أو المعزولة في حاوية إلى إضافة المتصفح. اختر علامة تبويب الإضافة وأنشئ رمز اتصال، ثم افتح الإضافة في ملف التعريف الذي سجّلت الدخول فيه، وأدخل الرمز وامنح الوصول إلى الموقع. لا يتجاوز الاستيراد الأصلي حماية Windows App-Bound ولا يضعف ملف تعريف المتصفح.

- **Chrome وEdge:** فك ضغط الحزمة واستخدم **تحميل إضافة غير مضغوطة** في صفحة إضافات المتصفح.
- **Firefox:** استخدم حزمة Firefox وخيار **تحميل إضافة مؤقتة** في `about:debugging`. تُزال الإضافات المؤقتة عند إعادة تشغيل Firefox. لا يتضمن هذا الإصدار توزيع إضافة موقّعة عبر المتجر.
- **ملف تعريف ارتباط:** يتوفر استيراد ملفات تعريف الارتباط بصيغتي JSON وNetscape كخيار بديل. استورد الملف مباشرةً في لوحة التحكم؛ ولا تلصق محتواه في محادثة مع الذكاء الاصطناعي.

ينقل المتصفح بيانات الجلسة مباشرةً إلى مخزن بيانات الاعتماد المحلي. تتلقى النماذج تسميات الحسابات وأسماء المفاتيح المحلية وبنية البيانات ونتائج الأدوات بعد إزالة قيم بيانات الاعتماد. ويمكنها إنشاء وصفة اتصال تشير إلى تلك القيم المحلية دون تلقيها. وتُراعى نطاقات ملفات تعريف الارتباط ومساراتها وانتهاء صلاحيتها ومعلومات التقسيم المدعومة، وتظل ترويسات المصادقة مقيدة بمصدرها الأصلي.

تُحدّد هوية الحساب من استجابة فعلية للموقع بشأن الحساب الحالي. ولا يُعدّ اسم ملف المتصفح الشخصي هوية مؤكدة للحساب على الموقع. إذا لم يُحدّد الحساب بعد، يوضح Hycli ذلك. بعد الربط، يمكن للتصفح العادي توفير استجابة الحساب وبُنى الطلبات المتاحة دون كشف قيم الطلبات أو ترويساتها أو محتوى الاستجابات للنموذج الذي يجهّز الأدوات.

قد يتطلب الموقع بيانات اعتماد API منفصلة وموثّقة أو إمكانية متصفح غير متاحة محليًا. يسجل التجهيز نتائج الاتصال والقراءة الفعلية. ولا يجعل جلب الصفحة الرئيسية أو إرجاع صفحة تسجيل دخول من API التكامل جاهزًا. يشرح [دليل إعداد المتصفح](../../browser-companion/guide.html) خطوات الإضافة وقيودها.

<a id="languages"></a>
## اللغات

تدعم لوحة التحكم اللغات العشرين المرتبطة أعلاه، بما فيها العربية من اليمين إلى اليسار. اللغة الأولية هي الإنجليزية. يُحفظ اختيارك على هذا الجهاز، ويمكن تجهيز أوصاف الذكاء الاصطناعي باللغة المحددة.

<a id="local-data"></a>
## البيانات المحلية وحدود الطلبات

تبقى تعريفات المواقع والبيانات الوصفية للحسابات والنشاط في مجلد البيانات المحلي. اضبط `HYCLI_DATA_DIR` لاختيار مكان آخر. استخدم **الإعدادات** لمعرفة المكان الحالي وطريقة حماية بيانات الاعتماد.

يستخدم مخزن بيانات الاعتماد مفتاح تشفير يحميه مخزن مفاتيح نظام التشغيل عند توفره. وإذا لم يتوفر مخزن المفاتيح، يوضح Hycli صراحةً أن الحماية تعتمد على أذونات الملفات فقط؛ وتقتصر صلاحيات المجلدات الخاصة وملفات بيانات الاعتماد على مستخدم نظام التشغيل الحالي. ولا يُستبدل المخزن المشفّر الموجود دون تنبيه إذا تعذّر فتح قفله.

تُرسل الطلبات بالتتابع وبوتيرة محددة لكل موقع وحساب، مع حد إضافي للموقع بأكمله. يراعي Hycli قيمة `Retry-After`، ويحد أحجام الاستجابات ومحاولات إعادة القراءة، ويوقف الطلبات مؤقتًا عند فشل المصادقة أو طلب الموقع تحققًا إضافيًا. أثناء تجهيز الموقع، لا يبدّل Hycli الحسابات أو يزيّف البصمات الرقمية أو يتجاوز التحقق؛ وقد يختلف سلوك التشخيص في المحرك. تقلل هذه الإجراءات الضغط الذي يمكن تجنبه، لكنها لا تضمن ألا يقيّد الموقع حسابًا أبدًا.

تُعطّل عناوين المواقع الخاصة والمحلية افتراضيًا. لموقع موثوق تستضيفه بنفسك، شغّل لوحة التحكم أو خادم MCP مع تحديد `--allow-local` صراحةً.

## التطوير والتحقق

```sh
npm --prefix dashboard ci
npm --prefix dashboard run check
npm --prefix dashboard run build
cargo test --all-targets --locked
cargo build --locked --bin hycli --example dashboard_fixture
node scripts/test-e2e.mjs --full
```

تستخدم الاختبارات مواقع محلية واستجابات مزوّدين مصطنعة. وتغطي ربط الموافقة بالطلب ومنع إعادة استخدامها، وإخفاء الأسرار، وإعادة التوجيه، وحدود الطلبات، وعدم إعادة طلبات التغيير، وحماية جلسات المتصفح، وتوافق استجابات المزوّدين مع البنية المتوقعة. لا تستخدم حسابًا حقيقيًا لإنشاء محتوى أو تعديله أو حذفه لمجرد اختبار Hycli.

تستخدم لقطات الشاشة وملف GIF بيانات تجريبية معزولة. راجع [مصادر الصور](../images/README.md).

## الترخيص والاستخدام المقصود

يُتاح Hycli بموجب ترخيص [Apache-2.0](../../LICENSE).

صُمّم Hycli لإنشاء أدوات سطر الأوامر واستخدامها لتسهيل التعامل مع المواقع. استخدمه مع المواقع والحسابات التي يُسمح لك بالوصول إليها.

يُقدّم البرنامج كما هو، دون ضمان. وبالقدر الذي يسمح به القانون، لا يتحمل المؤلفون والمساهمون المسؤولية عن الخسائر أو المشكلات الأخرى الناشئة عن استخدامه. أنت مسؤول عن كيفية استخدامه.

في حدود ما يسمح به القانون، لا يتحمل المؤلفون والمساهمون مسؤولية حظر الحسابات أو تعليقها أو تقييدها نتيجة استخدام Hycli. لا تستخدم Hycli للاختراق أو الوصول غير المصرح به أو شن الهجمات.
