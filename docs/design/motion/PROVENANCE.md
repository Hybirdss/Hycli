# Shima work motions

The shima-enaga mascot and its scurry, waiting and celebration sequences were generated for Hycli using image generation and Kling. Production prompts, intermediate images and source videos are not part of the public distribution.

The runtime assets in `dashboard/public/brand/motion/` contain 80 frames at 16 fps, with 192 × 160 pixel frames. Their manifest retains the original source filenames for attribution. The bird's position follows completed work stages; its animation conveys activity. Reduced-motion preferences freeze the sprite.
